# 配置与关联代码审计

审计范围：平台运行代码、插件 YAML 配置映射、前端构建变量、部署脚本、环境模板、测试及当前文档。第三方依赖、日志、生成 bundle 和明确标记的历史工件不作为配置消费者。

## 当前配置边界

| 能力 | 唯一入口 | 保留的配置 |
|------|----------|------------|
| LLM 供应商 | 管理端模型供应商配置 / 数据库 | 温度、超时、重试、限速、审计等非端点参数 |
| 向量模型 | 本地 bge-m3，1024 维 | 模型目录、缓存目录、首次下载源、推理线程、缓存容量 |
| 向量存储 | PostgreSQL + pgvector | DATABASE_URL、连接池参数 |
| 图存储 | Neo4j | 连接、认证和数据库，插件设置优先于环境默认 |
| 插件 | 部署允许集合 + 管理端启停 | PACKS_ENABLED、PACKS_CRITICAL、状态文件、依赖探针 |
| 数据存储 | PostgreSQL | 运行库与 pytest 专用库必须分离 |
| 外置重排 | 独立 rerank API | RERANK_*，不影响向量模型身份 |
| 前端宿主白名单 | Vite 构建进程 / frontend/.env | VITE_HOST_ORIGINS，不读取根后端 .env |

完整变量与默认值统一见 [环境模板](../.env.example)，不在多个文档复制全集。

## 清理范围

- 本地固定能力不保留远端向量实现、模型选择开关或为其他模型准备的查询前缀开关。
- LLM 端点和模型不从环境变量或构造期默认模型兜底；供应商配置缺失时明确报错。
- pgvector 工厂直接使用现有 PG 实现，不保留仅接受一个值的后端选择器。
- 测试隔离依赖独立 PostgreSQL 库，不依赖临时 SQLite 文件变量。
- 模型指纹和维度属于存量向量兼容性元数据，必须保留；模型不兼容时再次导入也不能自动启用，查询与块编辑同样禁止使用或混写旧模型向量。
- 配置说明只描述当前行为：管理端开放/口令两态、插件部署上限、根 .env 加载优先级、完整 Compose 服务依赖。

## 当前简化约束

- 离线 SQLite 迁移通过必填 `--sqlite` 显式提供源路径，运行数据库只使用 `DATABASE_URL`。
- 知识库抽取、实体合并、本体归纳和对话统一使用模型供应商配置，不提供插件专用模型覆盖。
- 数据源密码直接存于 PG 的 `password` 列并供连接使用；管理 API 不回显，日志不记录。运行代码不读取旧密文；旧连接需要时重新填写密码。
- 计量动作使用 `server/tool` 自动匹配或 `datasource_id/tool` 显式绑定，不通过环境变量绑定数据源。
- 资源上限、线程数、连接池、DDL 重试、日志和限速配置均有实际消费者。

## 需另行处理

1. **旧演示数据源**：停用的「演示库」保留原记录和未被消费的旧密文，当前密码字段为空。需要使用时在管理页填写正确密码；不保留加密回退或迁移前提。
2. **部署导入守卫认证**：任务 API 的认证与发布脚本队列检查需要真实端点联合验证；不能仅根据连接失败就认定队列为空。未在本次清理中改变任务守卫策略。
3. **Neo4j 替换**：见下节，当前仍为有效依赖，不属于废弃项。

## PostgreSQL 承接图存储评估

当前图模型为按知识库隔离的 Entity 节点和 RELATES 边，`sdk/graph_store.py` 提供现成 `GraphStore` 协议。实际业务以批量写入、名称/别名匹配、文档贡献删除、实体合并、浏览和有限跳邻域为主。邻域已由 Python 逐跳 BFS 执行，检索通常限制在 1～3 跳；未发现依赖 shortestPath、APOC/GDS 或任意 Cypher 执行的公开能力。

**建议：功能上可由 PostgreSQL 承接，先做协议等价验证，不直接下线 Neo4j。**

第一版复用 GraphStore 协议、现有 Python BFS 和平台 PG 连接池，建立知识库隔离的节点表、边表，使用事务、批量 upsert 和双向邻接索引。不要同时改写遍历算法。边唯一性必须保留块级证据，不能仅按实体对去重。

验证必须覆盖：实体合并的进出边迁移、别名和引用去重、自环处理、同实体多文档贡献、平行边证据聚合、重导幂等、删文档与整库删除、跨知识库隔离、循环和截断规则。

性能结论待证实：仓库没有真实图规模与延迟基线。高连接度、多种子、跨块边聚合会增加扫描量，返回节点/边上限不是扫描工作量上限。需以获准的快照比较 1～3 跳延迟和并发导入/向量检索对同一 PG 的影响。

迁移须停图写入并备份，直接迁原始节点与块级边，不通过 LLM 重抽取；对账原始边数、三元组数、引用完整性、属性摘要与端点完整性。切换和回退方案要覆盖切换后的新增写入。

本次不执行图存储迁移、不读取服务器数据、不更改 Neo4j 连接或容器。
