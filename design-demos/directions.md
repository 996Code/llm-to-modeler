## A1 · 仪器控制台 Instrument Console 【入选完整版 → dir-1】

- **逻辑与来源**：最佳设计师 A —— Dieter Rams / Braun 仪器面板传统（Ulm 学派，Ten Principles「好的设计是精密的」）
- **借的是什么**：暖浅灰面板分层（非纯白，仪器塑料机身色）；发丝刻度线做分隔与装饰二合一；单一信号色只给「激活态/主读数」；实体感控件（可按下的开关、读数窗凹槽）；全部数字 tabular-nums 等宽对齐；模块网格严格对齐
- **色彩推导（oklch 论证）**：底取仪器机身暖灰 oklch(0.955 0.005 85)≈#EDEBE6 一带（印刷油墨压灰的实验室质感，大面积 chroma≤0.01）；文字近黑炭色；信号色取量具/安全橙压低 chroma 至 0.13≈#D4550F，只给主 KPI 读数与激活态——计量现场的安全橙是仪器语言里唯一的「人话色」
- **主角素材**：数据即图像——主 KPI 做成仪器「读数窗」（大数字压刻度尺），检索类型做占比刻度条（真实比例 73/39/5），LLM 耗时做量程刻度（3580.8s 真实总耗时）
- **骨架**：顶部仪表带（品牌+状态读数+导航）→ 主读数区（会话/消息/LLM调用 三大表盘）→ 检索明细刻度条 → 插件模块卡（仪器槽位感，启用的点亮信号色）→ 组件样张带
- **胆量花在哪**：主 KPI 读数窗——数字底部压一条真实刻度尺（像仪表读数），全页唯一的大胆处
- **form 来自内容**：计量的本行是测量仪器，管理台就是一台仪器的面板——每个统计都是一个表盘读数

## A2 · 数据肖像 Data Portrait【备选，只做缩略图】

- **逻辑与来源**：最佳设计师 B —— Giorgia Lupi（Pentagram 合伙人，Data Humanism「数据是人不是数字」）
- **借的是什么**：小符号多维权编码（每条会话一个符号：形状=插件、填充=消息量、刺=事件）；必配图例教解码；有机路径排布不用网格；手作感线条
- **色彩推导**：手账米白底 + 4 个各绑语义的柔和色（会话蓝/消息绿/调用陶/检索芥黄），没有一个颜色是装饰
- **主角素材**：16 条真实会话画成 16 个符号的肖像带
- **骨架**：图例条 → 会话符号流 → 汇总段落
- **胆量**：概览页没有一张「卡」，全是符号+手写体注解
- **form 来自内容**：16 条会话是 16 个真人的问题，不是 4 个数字
- **未入选原因**：日常高频管理场景里符号系统扫读效率低于数字卡；作为方向偏「展览感」

## B1 · 暗色链路 Dark Trace【入选完整版 → dir-2】

- **逻辑与来源**：现实参照 A —— Linear（linear.app，当代后台事实标准，「The Linear Look」；基于长期已知设计语言归纳，本次未截图核对）
- **借的是什么**：近黑中性底（非深蓝）+ 1px 发丝边框网格分层（不用阴影）；单一 accent 只出现一种颜色；等宽字小标签（大写/宽字距）；键盘优先暗示（⌘K、快捷键提示）；微光渐变只允许一处（页面主标题区）
- **色彩推导**：底取中性近黑 oklch(0.17 0.003 260)≈#101112（避开 GitHub-dark #0D1117 蓝底禁区）；accent 把现有 8 个互不相认的品牌蓝收敛为一个——取 #3370ff 收暗为靛蓝 #6C8CFF（chroma 0.14，唯一品牌色）；语义绿/琥珀低饱和只做状态
- **主角素材**：链路流——158 个链路打点是这平台的灵魂（调用链路追踪），首屏画一条按真实占比分色的调用流向带（LLM 423 / 图谱 73 / 向量 39 / 全文 5）
- **骨架**：**左侧窄导航栏**（骨架区别于另两版）+ 主区 bento 网格卡（hairline 分隔，无阴影）
- **胆量花在哪**：首屏贯穿全宽的链路流向带，按真实数据着色，像示波器扫过一屏
- **form 来自内容**：LLM 平台的运行本质是「链路」（每次问答流经 路由→检索→LLM→工具），概览页第一屏就是链路本身

## C1 · 运行报告 Daily Report【撞版降级 → 备选完整稿 backup-report.html】

- **逻辑与来源**：秒数轮盘 web #12 —— 暖色出版物 Warm Editorial（Anthropic/Claude 谱系、Penguin 平装书排印）
- **借的是什么**：奶油纸底 + 衬线标题×无衬线正文混排；出版级版心与行高（1.7+）；节制分隔线（细规则线，不用卡片框）；一个强调色只做小面积点睛；报告式段落流（标题→导语→数据→注脚的节奏）
- **色彩推导**：底取未涂布纸 oklch(0.965 0.012 85)≈#F7F2E9；强调色从计量文化采样——检定证书的朱砂印泥压橙→赤陶 #B4531F（chroma 0.11，油墨感）；正文近黑墨 #201D1A。论证：计量院天天出具检定证书，纸+朱印是这个行业最深的视觉记忆
- **主角素材**：排印本身——衬线大数字（Tiempos 感）做每段的主角，真实统计写成「报告段落」
- **骨架**：刊头（产品名做报头）→ 报眼（日期范围+服务状态）→ 报告段落流（会话/调用/检索/插件 四段，非卡片网格，用规则线分区）→ 组件样张带
- **胆量花在哪**：概览页不是仪表盘，是一份「每日运行报告」的文档版面——没有一张卡片
- **form 来自内容**：计量行业的日常产物就是检定报告，平台概览=每日运行报告
- **降级原因（2026-11-03 compare 检查）**：与 A1 同为「浅暖纸底+近黑字+烧橙点缀」，色板距离 0.016（面积加权），两张放一起是近亲不是选择。完整稿保留在 backup-report.html 供直接选用

## C1′ · 包豪斯标准台 Bauhaus Standards【替补入选 → dir-3】

- **逻辑与来源**：风格库 web #10 包豪斯几何（Bauhaus Geometric；Khan Academy 品牌重塑谱系）——修撞版时按「换来源重做」替补第三席
- **借的是什么**：红/黄/蓝三原色块 + 黑白，纯平涂无渐变无阴影；方/圆/三角/四分之一圆等几何基本形做模块标识；严格栅格对齐；色块承担大面积（这是与另两版拉开色板距离的关键）
- **色彩推导**：三原色绑定三大能力域——智能问数=包豪斯蓝 #1D5FAE、知识库=包豪斯红 #C4361F、智能客服=芥黄 #E8A33D（均压 chroma 至油墨感）；白底 + 近黑 #17181A。论证：计量院是「标准」的守护者，包豪斯是现代标准化生产的视觉源头；三原色=三个能力域的标准色标，从此插件有身份、平台有品牌色系统
- **主角素材**：首屏一幅真实数据驱动的包豪斯几何构成（会话 16/消息 114/LLM 423/检索 117 按面积比例构成方圆阵）+ 色块模块卡
- **骨架**：白底 + 顶部黑色横带（品牌+导航）→ 几何构成首屏 → 色块模块统计区（每个域一个原色块）→ 插件名录（几何图标+域色标）→ 组件样张带
- **胆量花在哪**：首屏几何构成图——用真实统计画的包豪斯海报
- **form 来自内容**：计量=标准，包豪斯=标准之美的源头；三原色即三域色标
- **可读性红线**：色块上文字对比度必须 ≥4.5:1（蓝/红块上用白字需验证，黄块一律近黑字）
